# XREngineLab

Unity **2022.3.62f2c1** 的六个练习场景，对应引擎岗要亲手看过的几件事：畸变、双目、重投影、注视点、单 Pass、帧预算。不需要头显，用内置渲染管线，打开就能 Play。

## 打开

1. 用 Unity Hub 选编辑器 `2022.3.62f2c1`，打开本文件夹（里面有 `Assets`、`Packages`、`ProjectSettings`）。
2. 打开 `Assets/Scenes/01_Distortion.unity`，点 Play。
3. 左边是设置面板，底部六个按钮切换场景。Game 窗口尽量拉宽。

场景里的物体是 Play 之后由脚本生成的，编辑模式下是空的。
